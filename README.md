# dbt history

A public history app covering dbt from 2016 through v2, with guided Waffle Shop examples for a 20-minute video and independent browsing.

## Start building

Read [AGENTS.md](AGENTS.md), then the [app brief](documentation/01-app-brief.md) and [guided examples brief](documentation/02-guided-examples-brief.md).

The [documentation index](documentation/README.md) contains the complete handoff, sources and research inventories. The [visual prototype](documentation/visual-reference.html) establishes the design direction; guided walkthroughs still need to be implemented.

Application source and tooling belong at this project root. Planning, research and reference assets live in `documentation/`. The separate local dbt lab is superseded.
